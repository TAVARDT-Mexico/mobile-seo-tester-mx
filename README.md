Verificacion de configuracion viewport, dimensionamiento de contenido y experiencia movil optimizada.

***

## Capacidades de Diagnostico de SEO Movil

* **Configuracion de Meta Viewport**: Evaluacion estricta de `width=device-width` y proporciones de escala inicial para plataformas web.
* **Control de Diseno Responsive**: Deteccion de imagenes y bloques de ancho estatico causantes de scroll horizontal en celulares.
* **Espaciado y Objetivos Tactiles**: Validacion de zonas de interaccion en pantallas tactiles para evitar clics accidentales.
* **Verificacion de Fuentes Legibles**: Deteccion de textos de tamano inferior a los umbrales de lectura comoda.
* **Indice de Desempeno Mobile-First**: Evaluacion integral de 0 a 100 para optimizacion de comercio electronico y portales.

***

## Instalacion y Uso

Requiere Python 3.8 o superior sin librerias adicionales.

```bash
git clone https://github.com/TAVARDT/mobile-seo-tester-mx.git
cd mobile-seo-tester-mx
python mobile_seo_tester.py https://empresa.mx
```

Generacion de reporte en JSON:

```bash
python mobile_seo_tester.py https://empresa.mx -json
```
